# Multi AI 多引擎搜索

一个 Chrome 扩展（Manifest V3）：在**一个页面里同时打开多个搜索引擎与 AI 助手**，页面底部有一条统一输入框——输入一次，所有面板**同时搜索 / 同时开始对话**。

## 功能特性

- **多面板同屏**：单页网格同时展示多个站点面板（AI 助手 + 搜索引擎），面板数量与站点可自定义，面板自动平分整行宽度（1 个面板占满全屏，N 个面板 N 等分）。
- **一次输入，全网响应**：底部统一输入栏，输入内容后回车或点「发送」，所有搜索引擎面板立即跳转到结果页，所有 AI 面板自动填入问题并发起对话。
- **AI 站点一键同问**：内置 16 个 AI 助手适配器，自动定位输入框、填入文本并触发发送：
  豆包、DeepSeek、通义千问、腾讯元宝、Kimi、ChatGPT、Claude、Gemini、Copilot、Poe、Mistral、You、Yep、Blackbox AI、thinkany.ai、Brave Leo。
- **40+ 搜索引擎**：百度、搜狗、必应中国、知乎、Google、Bing、DuckDuckGo、Brave Search 等，并支持**自定义搜索引擎**（URL 模板，`%s` 为查询占位）。
- **工作区预设**：AI 全家桶 / 全球搜索 / 中文搜索，一键切换面板组合；也可把当前面板组合存为自定义工作区。
- **不重载体验**：增删/移动面板采用增量渲染，已有面板的页面不会重新加载；移除的面板会被缓存复用。
- **深色 / 浅色主题**。
- **站点内嵌与 UA 处理**：通过 `declarativeNetRequest` 移除目标站点拒绝内嵌的响应头（X-Frame-Options / CSP），并对主流搜索引擎改写移动端 UA，以获得更好的内嵌效果。

## 安装（开发者模式加载）

1. 下载或克隆本仓库；
2. 打开 Chrome 地址栏输入 `chrome://extensions`；
3. 开启右上角「开发者模式」；
4. 点击「加载已解压的扩展程序」，选择本项目目录；
5. 点击扩展图标或打开扩展主页 `chrome-extension://<id>/pages/app.html` 开始使用。

> 部分 AI 站点需要先登录账号（可在面板右上角「↗」新标签页中登录）；游客可直接使用的站点（如 Mistral、You 等）开箱即用。

## 使用方法

- **同时搜索**：在底部输入框输入问题 → 回车。所有搜索引擎面板同步跳转结果页，所有 AI 面板同步发起对话。
- **自定义面板**：点顶栏「＋ 面板」选择站点；点面板名称可替换站点；面板右上角提供刷新 / 新标签页打开 / 移除。
- **切换工作区**：点顶栏「AI 全家桶 / 全球搜索 / 中文搜索」即可整体切换面板组合。
- **自定义搜索引擎**：「⚙ 设置」→ 自定义搜索引擎，填写名称与含 `%s` 的 URL 模板。
- **状态徽标**：每个 AI 面板头部显示发送状态（就绪 / 发送中 / 已发送 / 未登录或需登录 / 未找到输入框）。

## 项目结构

```
multi-ai/
├── manifest.json          # MV3 清单：权限、host 白名单、内容脚本
├── background.js          # 后台：DNR 规则、右键菜单
├── common/sites.js        # 站点清单（AI 助手 + 搜索引擎）与默认面板
├── content/adapter.js     # 16 个 AI 站点适配器（填框 + 触发发送 + 回执）
├── pages/                 # 主页面（app.html/css/js）与弹窗（popup）
├── icons/                 # 扩展图标 16/32/48/128
├── docs/                  # 站点验收登记表
├── tools/                 # 打包脚本 pack_zip.py、图标生成脚本 gen_icons.py
└── store-assets/          # Chrome 应用商店上架素材（文案 + 截图目录）
```

## 打包（Chrome Web Store 上架用）

```bash
python tools/pack_zip.py
# 生成 multi-ai-<version>.zip，直接用于商店上传
```

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存面板配置、工作区、自定义搜索引擎、主题 |
| `contextMenus` | 右键菜单快速调用本扩展搜索 |
| `declarativeNetRequest` | 移除站点拒绝内嵌的响应头（实现同屏展示），并为搜索引擎改写移动 UA |

Host 权限采用**白名单制**（仅包含已内置的 AI 站点与搜索引擎域名），不使用 `<all_urls>`。扩展不包含远程代码，不上传任何用户数据。
