## 2. 简短描述（≤ 132 字符）

```

```

## 3. 详细描述（商店「说明」栏目）

```
Multi AI 多引擎搜索：一次输入，多引擎同搜、多 AI 同问。

在一个页面里同时打开你常用的搜索引擎与 AI 助手。页面底部只有一条输入框——
输入内容后按回车，所有搜索引擎面板同时跳转结果页，所有 AI 面板同时填入问题并发起对话，
无需在多个标签页之间来回切换。

主要功能：
· 多面板同屏：单页网格同时展示多个站点面板，数量与站点可自定义，面板自动平分整行宽度；
· 一次输入、全网响应：底部统一输入栏，回车即可让所有面板同时搜索 / 同时对话；
· 内置 16 个 AI 助手：豆包、DeepSeek、通义千问、腾讯元宝、Kimi、ChatGPT、Claude、
  Gemini、Copilot、Poe、Mistral、You、Yep、Blackbox AI、thinkany.ai、Brave Leo；
· 40+ 搜索引擎：百度、搜狗、必应中国、知乎、Google、Bing、DuckDuckGo、Brave Search 等，
  并支持自定义搜索引擎（URL 模板）；
· 工作区预设：AI 全家桶 / 全球搜索 / 中文搜索，一键切换；也可保存自定义工作区；
· 面板增删不重载：调整面板时其余页面保持不动；
· 深色 / 浅色主题。

使用方法：
1. 安装后打开扩展主页；
2. 在底部输入框输入问题，按回车；
3. 所有搜索引擎与 AI 面板同时响应；AI 面板右上角可查看发送状态；
4. 通过「＋ 面板」自定义面板组合，「⚙ 设置」管理主题、工作区与自定义搜索引擎。

隐私说明：
· 本扩展不收集、不上传任何用户数据；
· 不使用远程代码；host 权限为白名单制，仅覆盖内置站点域名。
```

## 4. 权限用途说明（商店审核「权限用途」）

| 权限 | 用途说明 |
| --- | --- |
| storage | 保存面板配置、工作区、自定义搜索引擎与主题偏好 |
| contextMenus | 提供右键菜单，快速用本扩展搜索选中文字 |
| declarativeNetRequest | 移除目标站点拒绝 iframe 内嵌的响应头（X-Frame-Options / Content-Security-Policy），实现多站点同屏展示；并对搜索引擎改写移动 UA 以获得更佳内嵌效果 |
