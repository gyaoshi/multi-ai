Multi AI 多引擎搜索 —— 隐私权政策

生效日期：2026 年 9 月 30 日

一、概述

「Multi AI 多引擎搜索」（以下简称“本扩展”）是一款 Chrome 浏览器扩展，用于在单一页面内同时展示多个搜索引擎与 AI 助手网站，并在底部统一输入栏输入一次后，同时向各面板发起搜索或对话。

本扩展由 gyaoshi 开发并发布。本政策说明本扩展对用户数据的处理方式。

二、数据收集

本扩展不收集任何个人信息，不收集任何使用数据，不上传任何用户数据。

  • 不收集浏览历史、网页内容、表单输入、登录凭据、Cookie 或任何个人身份信息；
  • 不包含任何远程代码、不调用任何外部脚本或远程配置、不向开发者服务器发送任何请求；
  • 本扩展完全在本地运行。

三、本地与同步存储

为保存你的偏好设置（面板组合、工作区、自定义搜索引擎、主题），本扩展使用 Chrome 的 chrome.storage.sync 存储，数据仅保存在你自己的设备与你登录的 Chrome 同步账户中，由 Chrome 官方同步机制管理，扩展开发者无法访问。

在非扩展环境（例如以本地文件预览）中，设置会保存在浏览器的 localStorage 中，同样仅存在于你自己的设备。

四、与第三方网站的交互

本扩展会在页面中嵌入（iframe）你自行选择的搜索引擎与 AI 助手网站。当你使用底部输入栏输入并发送时，文本会被填入这些网站各自的输入框并提交给对应网站——这与你在这些网站上直接输入、直接提问完全相同。

  • 你提交的内容将受目标网站的隐私政策与服务条款约束，而非本扩展；
  • 本扩展不读取、不保存、不传输你在面板中的对话内容；
  • 请注意：请勿在输入栏中输入你不愿公开给目标网站的敏感信息。

五、权限用途

权限用途
storage保存面板配置、工作区、自定义搜索引擎与主题偏好。
contextMenus提供右键菜单，用本扩展快速搜索选中的文字。
declarativeNetRequest移除目标站点拒绝 iframe 内嵌的响应头（X-Frame-Options / CSP），使多站点能在同一页面展示；并为搜索引擎改写移动 UA 以获得更好的内嵌效果。
主机权限（白名单域名）仅覆盖内置的 AI 助手与搜索引擎域名，用于内容脚本与上述网络规则；不使用 <all_urls>。

六、数据共享与出售

本扩展不与任何第三方共享、出售或披露用户数据。由于不收集数据，亦不存在数据保留或删除问题。

七、未成年人

本扩展不针对未成年人，也无针对性的数据收集行为。

八、政策更新

如本政策发生变更，将在本页面更新并标注新的生效日期。重大变更会通过扩展更新说明告知。

九、联系我们

如对本政策有任何疑问，请通过 GitHub 仓库提交 Issue：https://github.com/gyaoshi/multi-ai

English

Multi AI Multi-Search — Privacy Policy

Effective date: September 30, 2026

1. Overview

"Multi AI Multi-Search" (the "Extension") is a Chrome browser extension that displays multiple search engines and AI assistant websites side by side on a single page, and sends one query from a unified input bar to all panels at once.

The Extension is developed and published by gyaoshi. This policy explains how the Extension handles user data.

2. Data Collection

The Extension does not collect any personal information, any usage data, or upload any user data.

  • It does not collect browsing history, page content, form input, credentials, cookies, or any personally identifiable information;
  • It contains no remote code, loads no external scripts or remote configuration, and sends no requests to any developer-controlled server;
  • The Extension runs entirely locally.

3. Local and Sync Storage

To save your preferences (panel layout, workspaces, custom search engines, theme), the Extension uses Chrome's chrome.storage.sync. Data is stored only on your own device and in your logged-in Chrome sync account, managed by Chrome's official sync mechanism; the developer cannot access it.

In non-extension contexts (e.g., previewing as a local file), settings are stored in the browser's localStorage, again only on your own device.

4. Interaction with Third-Party Websites

The Extension embeds (via iframes) the search engine and AI assistant websites you choose. When you type in the unified input bar and send, the text is placed into each website's own input field and submitted to that website — exactly as if you had typed and asked on those websites directly.

  • Content you submit is governed by the privacy policy and terms of service of the target website, not by the Extension;
  • The Extension does not read, store, or transmit your conversations inside the panels;
  • Please do not enter sensitive information you would not want shared with the target websites.

5. Permission Usage

PermissionPurpose
storageSave panel layout, workspaces, custom search engines, and theme preferences.
contextMenusProvide a right-click menu to quickly search selected text with the Extension.
declarativeNetRequestRemove response headers (X-Frame-Options / CSP) that prevent iframe embedding, so multiple sites can display on one page; rewrite the User-Agent for search engines for a better embedded experience.
Host permissions (whitelisted domains)Cover only the built-in AI assistant and search engine domains, used by content scripts and the rules above; <all_urls> is not used.

6. Sharing and Sale of Data

The Extension does not share, sell, or disclose user data to any third party. Since no data is collected, there is nothing to retain or delete.

7. Children

The Extension is not directed at children and performs no targeted data collection.

8. Policy Changes

If this policy changes, this page will be updated with a new effective date. Significant changes will be communicated through extension update notes.

9. Contact

For any questions about this policy, please open an issue on the GitHub repository: https://github.com/gyaoshi/multi-ai
